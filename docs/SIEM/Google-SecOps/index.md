# Google SecOps

O **Google Security Operations** (antigo Chronicle) é a plataforma de SIEM e SOAR do Google Cloud. Os dados ingeridos são normalizados no **UDM** (Unified Data Model) e as detecções são escritas em **YARA-L 2.0**.
