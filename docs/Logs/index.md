# Logs

Logs são o registro do que acontece em sistemas, aplicações e redes. Para o Blue Team, eles são a matéria-prima para detectar ataques, investigar incidentes e alimentar o SIEM.

## O que você vai encontrar aqui

- Quais logs coletar e por quê
- Como ler e interpretar cada tipo de log
- Eventos importantes para detecção e investigação

## Fontes de log

| Fonte | Conteúdo |
|-------|----------|
| [Windows](windows.md) | Event Logs, eventos de segurança e Sysmon |
| [Linux](linux.md) | syslog, journald e auditd |
| [Rede](rede.md) | Firewall, DNS e proxy |

!!! tip "Relacionado"
    Para centralizar e correlacionar esses logs, veja a seção [SIEM](../SIEM/index.md).
